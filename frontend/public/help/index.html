Windows 一键安装与配置

双击运行 CMD，无需手动编辑配置文件。已有应用时会跳过安装。

ambi-setup-windows.cmd
  1. 打开下载文件，输入你在 本站 API Keys 页面创建的密钥。
  2. 选择支持 Responses 接口的对话模型。
  3. 缺少 winget 时，按系统提示授权安装。脚本会先搜索应用，再按确认的官方 ID 安装。
  4. 完成后使用 Codex 本地的 Windows 原生模式；WSL 需要单独配置。

macOS 一键安装与配置

解压后双击运行；无需先安装 Homebrew。支持 macOS 13 及更新版本。

ambi-setup-macos.zip · 内含可执行 .command
  1. 下载 ZIP 并解压，双击 Ambi-Setup.command。
  2. 在弹窗中输入本站 API Key，选择支持 Responses 接口的对话模型。
  3. 已有 Homebrew 时自动使用 brew；否则从 OpenAI 官方更新源下载并验证应用签名。
  4. 完成后打开桌面应用，使用 Codex 本地模式。
配置范围：脚本设置桌面应用的 Codex 本地模式；ChatGPT Classic 和其他聊天功能的账号登录另行处理。若应用已打开，请完全退出再重开。系统可能要求确认运行或授权安装；浏览器下载后仍需打开文件。查看官方网关说明 ↗
配置与恢复　脚本会先备份，再重建 config.toml，旧设置（包括 MCP 等）需要从备份手动合并。备份保存在同目录的 config.toml.ambi-backup.*；如需恢复，退出应用后将备份复制回 config.toml，再打开应用。API Key 保存在本机配置文件中，仅授予当前用户访问权限。Windows 缺少 winget 时会运行 asheroto.com/winget 第三方脚本。
01 / INSTALL

也可以手动安装

优先使用 ChatGPT 官方网站下载；熟悉命令行的用户也可以通过包管理器安装。

Windows

winget 或官网下载

打开 PowerShell 或 Windows Terminal。如果提示“无法识别 winget”或系统尚未安装 winget，请先以管理员身份打开 PowerShell，运行以下命令安装：

irm asheroto.com/winget | iex
脚本说明　此命令会下载并立即运行第三方 asheroto/winget-install 安装脚本 ↗，请确认信任该来源后使用。Windows 桌面系统需为 Windows 10 1809 或更高版本，或 Windows 11。

安装完成后重新打开终端；已有 winget 的用户可直接从这里开始。先搜索 ChatGPT：

winget search ChatGPT --source msstore

在搜索结果中确认官方 ChatGPT，记下其 Id 列。将下面命令中的 查到的ID 替换为该值后运行：

winget install --id "查到的ID" --exact --source msstore
前往 ChatGPT 官方下载 ↗Microsoft Store ↗
提示　安装前请核对搜索结果的名称、来源与官方商店页面。若找不到或安装失败，可通过 Microsoft Store 或官网下载安装。

macOS

Homebrew 或官网下载

如果已安装 Homebrew，在终端粘贴命令即可。ChatGPT for macOS 需要受支持的 macOS 版本。

brew install --cask chatgpt
前往 ChatGPT 官方下载 ↗安装 Homebrew ↗
提示　若 Homebrew 提示找不到 cask 或设备不兼容，请使用官网页面查看当前支持情况并下载。

03 / HELP

常见问题

脚本具体配置了什么？

脚本为新版桌面应用的 Codex 本地模式设置自定义 Responses 网关。其他聊天功能仍按各自账号使用，ChatGPT Classic 不适用。

为什么点击按钮后还需要打开文件？

浏览器只能下载脚本，系统安装仍需用户打开文件并完成授权。Windows 打开 CMD；Mac 解压 ZIP 后双击 .command，按系统提示确认运行。

API 地址应该填什么？

本站统一使用 https://sub.ambi.vip/v1。脚本已自动填写，用户只需输入自己的 API Key 并选择可用模型。

在哪里创建 API Key？

登录对应的 Sub2API 用户面板，进入令牌或 API Keys 页面创建。不同站点的菜单名称和可用模型可能有所不同。
